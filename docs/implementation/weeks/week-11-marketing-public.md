# Week 11 — Marketing + Public Efficiency

## Outcome
Close the first measurable loop from marketing/content to commercial outcome while making public content delivery more sustainable.

## Dependencies
Stable CRM/Quote identifiers and Week 01 dependency/framework baseline.

## Primary work
- `marketing_campaigns` and minimum `marketing_publications`;
- `attribution_touchpoints` normalized from known campaign/publication/content context;
- propagate identifiable attribution to Opportunity/Quote/Won reporting;
- basic editorial publish/schedule/expiry improvements;
- public catalog/content cache invalidation strategy based on the pinned framework version.

## Required context
Volume I marketing/content rules; Volume II Marketing Studio/Public/CMS; Volume III Marketing + Public web/CMS. Inspect existing Meta attribution and catalog code narrowly.

## Suggested Changes
1. `marketing-campaign-foundation`
2. `publication-calendar-foundation`
3. `normalized-attribution`
4. `public-content-cache-invalidation`

## Completion gate
Known campaign/publication context can be traced to commercial entities without discarding raw attribution evidence; public publication/archival invalidates content predictably; no Canva-like editor or automatic social publishing is required.
